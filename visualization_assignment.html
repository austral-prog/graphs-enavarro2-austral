1. Gráfico de Líneas: Curva de Optimización Cognitiva¶

Este gráfico ilustra la evolución de los niveles de concentración y productividad de un desarrollador tras la primera taza de la mañana (08:00 AM). Se eligió esta visualización de serie temporal para demostrar el "boost" inmediato de la cafeína y la importancia de la ventana de mantenimiento para evitar el crash de media tarde.

tiempo = np.arange(8, 18, 0.5) # De 8am a 5pm

4. Gráfico de Dispersión: Granulometría vs. Calidad de Extracción¶

Aquí analizamos la relación entre el tamaño de la molienda (en micras) y el puntaje de sabor (1-100). Elegí el gráfico de dispersión para identificar el "punto dulce" (Sweet Spot); se observa claramente que una molienda ni muy gruesa ni muy fina es la clave para evitar la sub-extracción o el amargor excesivo.

In [19]:
# Datos simulados: molienda (x) vs sabor (y)
molienda_micras = np.random.uniform(200, 1000, 80)
sabor_score = 100 - 0.0003 * (molienda_micras - 600)**2 + np.random.normal(0, 3, 80)

plt.figure(figsize=(8, 5))
plt.scatter(molienda_micras, sabor_score, c=molienda_micras, cmap='BrBG', s=60, edgecolors='black', alpha=0.7)

plt.title('Relación: Tamaño de Molienda y Calidad del Sabor', fontsize=14, fontweight='bold')
plt.xlabel('Tamaño de Molienda (Micras)', fontsize=12)
plt.ylabel('Puntaje de Cata (0-100)', fontsize=12)
plt.colorbar(label='Granulometría')
plt.grid(True, linestyle=':', alpha=0.6)

5. Heatmap: Correlación entre Variables de Preparación¶

Este gráfico avanzado (Mapa de Calor) muestra la interdependencia entre la temperatura del agua, el tiempo de contacto, la presión y el rendimiento de la extracción. Es la visualización definitiva para un entusiasta del café, ya que permite ver matemáticamente cómo la temperatura y el tiempo son los factores críticos para lograr la taza perfecta.

import pandas as pd

# Crear matriz de correlación simulada
data = {
    'Temp. Agua': [1, 0.85, 0.4, 0.7],
    'Tiempo Ext.': [0.85, 1, 0.3, 0.65],
    'Presión (Bars)': [0.4, 0.3, 1, 0.5],
    'Cuerpo/Textura': [0.7, 0.65, 0.5, 1]
}
df_corr = pd.DataFrame(data, index=['Temp. Agua', 'Tiempo Ext.', 'Presión (Bars)', 'Cuerpo/Textura'])

plt.figure(figsize=(8, 6))
sns.heatmap(df_corr, annot=True, cmap='YlOrBr', fmt='.2f', linewidths=1)

plt.title('Correlación de Variables en el Método Espresso', fontsize=14, fontweight='bold')
plt.savefig('imgs/custom_plot.png', dpi=300, bbox_inches='tight')
